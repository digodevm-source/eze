# Сайт Global Group Holding с карточкой Global Group Development

В папке `site/` лежит полная копия сайта [ggholding.ru](https://ggholding.ru/). В блок «Группа компаний GGH» на главной добавлена карточка ООО «Глобал Групп Девелопмент», которая ведёт на наш сайт.

В копии 39 страниц, они связаны между собой как на настоящем сайте:

- главная;
- «Проекты», «Международное сотрудничество», «Аналитика», «Новости»;
- страницы компаний ФЛК, «Русжелдор агентство», «АПК Глобал Групп» и их формы заявок;
- все 27 новостей и статей.

| Папка / файл | Что это |
| --- | --- |
| `site/` | Готовый сайт: эту папку загружают на хостинг |
| `source/` | Страницы, сохранённые с ggholding.ru, из них собирается `site/` |
| `build_site.py` | Сборка `site/` из `source/` |
| `ggd-card.png` | Картинка карточки (700 × 1178, как у остальных компаний) |
| `ggd-logo.png`, `ggd-mark-gold.svg` | Логотип Global Group Development |

## Как посмотреть

1. Откройте папку проекта в VS Code.
2. Если внизу слева горит **Restricted Mode**, нажмите его и выберите **Trust**.
3. Найдите файл `ggh/site/index.html`, нажмите на него правой кнопкой и выберите **Open with Live Server**.

Работают меню, слайдер компаний, все «Подробнее», новости и переходы между страницами. Клик по карточке Global Group Development открывает наш сайт из папки `dist/`.

## Перед загрузкой на хостинг

Когда купите домен для Global Group Development, пересоберите копию с адресом сайта, чтобы карточка вела на него:

```bash
python3 ggh/build_site.py https://ваш-домен.ru/
```

Потом загрузите **содержимое** папки `ggh/site/` в корень хостинга сайта холдинга.

## Что важно знать

- **Картинки, шрифты и скрипты** загружаются с серверов Tilda, как и на сейчас работающем сайте. Пока проект в Tilda существует, всё отображается.
- **Формы** («Запросить звонок», заявки) отправляются через Tilda. Tilda принимает их только с домена ggholding.ru, поэтому на компьютере они не отправятся, а на ggholding.ru будут работать.
- **Новости** вшиты в страницы. Ленты Tilda показывают новости только на домене ggholding.ru, поэтому в копии они собраны прямо в HTML. Если в Tilda добавят новую новость, сохраните её страницу в `source/` и пересоберите.
- **Карточки без страниц:** у «ТрансЛайн Памир», «СаудаСев» и «Глобал Групп Консалтинг» на сайте холдинга нет своих страниц. «Подробнее» там не ссылка и в оригинале, поэтому никуда не ведёт.
- **Битая ссылка в оригинале:** на странице АПК есть ссылка `/vehicles`, она не работает и на настоящем сайте.

## Если сайт холдинга остаётся на Tilda

Тогда проще добавить карточку прямо в Tilda, а копия не нужна:

1. Откройте главную ggholding.ru в Tilda.
2. Выберите блок «ГРУППА КОМПАНИЙ GGH» (T1196) → **Контент**.
3. Добавьте карточку в конец:
   - изображение `ggd-card.png`;
   - заголовок «ООО «Глобал Групп Девелопмент»»;
   - описание «Российская Федерация»;
   - кнопка «Подробнее» со ссылкой на наш домен.
4. Нажмите **Опубликовать**.
