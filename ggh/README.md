# Карточка Global Group Development на сайте Global Group Holding

Материалы, чтобы добавить компанию в блок «Группа компаний GGH» на [ggholding.ru](https://ggholding.ru/).

| Файл | Что это |
| --- | --- |
| `ggd-card.png` | Картинка для карточки, 700 × 1178 px — тот же формат, что у остальных компаний в блоке |
| `ggd-logo.png` | Логотип на прозрачном фоне (для документов, презентаций, соцсетей) |
| `ggd-mark-gold.svg` | Знак логотипа в векторе, золотой градиент |
| `preview.html` | Макет блока с новой карточкой: как это будет выглядеть на сайте холдинга |

## Как посмотреть макет

Откройте `ggh/preview.html` через Live Server (правый клик → **Open with Live Server**). Новая карточка — последняя, она выделена рамкой. Клик по ней открывает наш сайт из папки `dist/`.

## Как добавить карточку на сайт холдинга (Tilda)

Делать после того, как куплен домен и сайт Global Group Development опубликован.

1. Войти в Tilda, открыть страницу главной ggholding.ru.
2. Найти блок «ГРУППА КОМПАНИЙ GGH» (слайдер карточек, блок T1196) → **Контент**.
3. Добавить новую карточку в конец списка и заполнить:
   - **Изображение:** `ggd-card.png`;
   - **Заголовок:** ООО «Глобал Групп Девелопмент» (проверьте точное юридическое название);
   - **Описание:** Российская Федерация;
   - **Текст кнопки:** Подробнее;
   - **Ссылка кнопки:** адрес нашего сайта, например `https://ваш-домен.ru/`; отметить «Открывать в новом окне».
4. Сохранить и нажать **Опубликовать**.

Если у блока в настройках есть опция ссылки на всю карточку, включите её — тогда переход будет по клику на любое место карточки, а не только на «Подробнее».
