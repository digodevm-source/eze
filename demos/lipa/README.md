# Lipa — сайт цветочного магазина

Демо-сайт для магазина Lipa (Москва, ул. Нижние Мнёвники, 9). Его нужно показать владельцу до того, как о нём договоримся. Страница закрыта от поисковиков (`noindex`).

Статический HTML, CSS и JS без сборки. Чтобы открыть локально:

```bash
cd demos/lipa && python3 -m http.server 8000
# http://localhost:8000
```

## Экраны

| Экран | Что происходит |
|---|---|
| Первый экран | Крупное LIPA и три фото. При прокрутке центральное фото раскрывается на весь экран, боковые разъезжаются, появляется «Свежие цветы каждый день» |
| О магазине | Текст проявляется слово за словом по мере прокрутки |
| Букеты | На компьютере лента едет вбок при прокрутке вниз, на телефоне листается пальцем |
| Цветы к столу | Фото открывается снизу вверх, заголовок поднимается по словам |
| 4,9 | Оценка с Яндекс Карт, ведёт на карточку магазина |
| Заказать букет | Telegram, телефон, адрес, метро, время открытия |
| Подвал | Большое LIPA, подпись dgd studio |

Прокрутка колесом плавная (Lenis). На телефоне и планшете прокрутка остаётся системной. При настройке «Уменьшить движение» анимации отключаются.

## Что уточнить у владельца

- **Telegram:** ник или ссылка. Пока кнопка открывает чат по номеру телефона. Ник вписывается в `CONFIG.telegram` в `assets/js/main.js`.
- **Часы работы:** известно только время открытия, 10:00.
- **Оформление столов:** взято из фото в их канале, нужно подтвердить, что они это делают.
- **Цены:** указаны только известные (моно-букет за 5 000 ₽ и розы от 400 ₽). Остальные букеты подписаны без цены.
- **Оплата наличными:** на картах указана только оплата картой.

## Фото

Фото взяты из Telegram-канала магазина. Сейчас стоят временные вырезки из скриншотов (около 440 px), поэтому на большом экране они мыльные. Когда будут оригиналы, их нужно положить в одну папку с теми же именами и прогнать через скрипт:

```bash
python3 tools/prep-photos.py <папка с оригиналами> demos/lipa/assets/img
```

| Файл | Где на сайте |
|---|---|
| `basket` | центральное фото первого экрана, лента |
| `peonies`, `roses-mono` | боковые фото первого экрана, лента |
| `roses`, `autumn`, `chrysanthemums`, `amaryllis`, `daisies`, `peach` | лента букетов |
| `table` | «Цветы к столу» |
| `autumn-girl` | блок заказа |

Скрипт делает два размера: `name.webp` (до 1800 px) и `name-sm.webp` (до 900 px).
