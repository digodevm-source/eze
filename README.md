# Altai Ridge — сайт коттеджного посёлка

Одностраничный сайт-презентация в формате «слайдов»: 10 полноэкранных карточек, которые плавно сменяют друг друга. Текущая уходит вглубь и затемняется, следующая наезжает поверх.

## Запуск

Сборка не нужна, это чистые HTML, CSS и JS. Достаточно открыть `index.html` или поднять любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Публикация: GitHub Pages (Settings → Pages → Deploy from branch → корень), Netlify, Vercel или любой хостинг статики.

### Плавность

- **Lenis** отвечает за инерционный плавный скролл.
- **GSAP ScrollTrigger** закрепляет каждую карточку, пока следующая наезжает поверх; старая уменьшается и затемняется.
- **Доводка до слайда**: если остановить скролл между слайдами, страница сама плавно доезжает до ближайшего по направлению движения.
- **Клавиатура**: `↓` / `↑`, `PageDown` / `PageUp`, `Space`, `Home`, `End` переключают слайды.
- На телефонах и низких экранах (уже 1024 px или ниже 620 px) включается обычная прокрутка с анимациями появления.
- При системной настройке «Уменьшить движение» анимации отключаются.

## Как редактировать

- **Тексты, цены, характеристики** находятся в `index.html`. Характеристики проектов лежат в атрибутах кнопок `.plist__item` (`data-price`, `data-area` и т. д.).
- **Фото** лежат в `assets/img/`, у каждого два размера: `name.webp` (большой) и `name-sm.webp` (до 960 px). Чтобы поставить свои рендеры, замените файлы с теми же именами.
- **Цвета и шрифты** задаются переменными в начале `assets/css/style.css` (`--accent`, `--bg` …).
- **Отправка заявок.** Сейчас форма проверяет поля и показывает «Спасибо», но никуда не отправляет. Чтобы подключить CRM, почту или Telegram-бота, задайте адрес обработчика перед подключением `main.js`:

  ```html
  <script>window.ALTAI_FORM_ENDPOINT = 'https://your-backend.example/lead';</script>
  ```

  Данные уходят POST-запросом в JSON: `name`, `phone`, `format`, `comment`, `subject`.

> Цифры, цены, телефон, e-mail и домен взяты из макета или придуманы как заглушки. Перед публикацией замените их на реальные.

## Структура

```
index.html
assets/
  css/style.css      — стили
  js/main.js         — анимации и интерактив
  vendor/            — gsap 3.12.5, ScrollTrigger, lenis 1.1.20
  fonts/             — Jost и Manrope (variable, кириллица и латиница)
  img/               — фото в WebP
```
