# nightly

Тёмный одностраничный сайт креативной студии **nightly** (identity, motion, 3D).
Статический HTML/CSS/JS без сборки: его можно положить на любой хостинг, включая GitHub Pages.

## Структура страницы

| Экран | Видео | Раскладка |
|---|---|---|
| 1. Hero | `sphere`: чёрная сфера (исходник №4) | текст слева, видео справа |
| 2. Identity | `radiance`: лицо из лучей (исходник №3) | видео слева, текст справа |
| 3. Motion | `rain`: фигура под дождём (исходник №2) | текст слева, видео справа |
| 4. 3D & CGI | `offering`: женщина из частиц (исходник №1) | видео слева, текст справа |
| 5. Studio | без видео | манифест и три принципа |
| Футер | без видео | крупный логотип, год, местное время посетителя |

Текст всегда стоит в своей колонке на чёрном фоне и никогда не перекрывает видео.
На телефоне видео идёт первым, текст под ним.

## Как сделаны бесшовные циклы

- `assets/video/<name>.seg.mp4`: фрагментированный MP4, в котором целое число циклов (около 2 с).
  Скрипт `assets/js/main.js` подаёт его в MediaSource снова и снова, встык.
  Видео никогда не перематывается на 0, поэтому на стыке нет ни паузы, ни рывка.
- `assets/video/<name>.mp4`: обычный MP4 (около 5 с). Запасной вариант для браузеров без
  MediaSource (старые iPhone); играет с атрибутом `loop`.
- Чёрный фон роликов «прижат» к чистому `#000` и совпадает с фоном страницы, поэтому краёв кадра не видно.
- Видео за пределами экрана ставится на паузу и запускается заранее, до того как появится на экране.
- Если браузер заблокировал автозапуск (например, режим энергосбережения на iOS),
  видео стартует при первом касании.

Исходные ролики лежат в `media-src/`. Чтобы перекодировать их после замены, нужен `ffmpeg`:

```sh
tools/encode-videos.sh
```

## Локальный запуск

MediaSource не работает с `file://`, поэтому откройте сайт через любой локальный сервер:

```sh
python3 -m http.server 8000
# затем http://localhost:8000
```

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → выберите ветку и папку `/ (root)`.

## Что внутри

- `index.html`: разметка и тексты (на английском).
- `assets/css/style.css`: стиль, цвета и шрифты задаются переменными в `:root`.
  Шрифты: Cormorant Garamond и Hanken Grotesk (Google Fonts).
- `assets/js/main.js`: бесшовные циклы, плавный скролл, мягкое появление блоков,
  лёгкий параллакс видео, часы.
- `assets/vendor/lenis.min.js`: Lenis 1.3.26 (MIT), плавный скролл.

Если в системе включено «уменьшение движения», плавный скролл, параллакс и анимации появления
отключаются, а сами видео продолжают крутиться.
