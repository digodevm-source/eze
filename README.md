# Solis Art — La Victoire de Samothrace

Одностраничный сайт по референсу «Solis Art»: тёмная эстетика, статуя на чёрном, плавный «видео»-скролл.

## Как открыть

Статический сайт, сборка не нужна:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

(Можно открыть и `index.html` напрямую, но через локальный сервер шрифт и всё остальное грузятся надёжнее. Подходит любой статический хостинг, например GitHub Pages.)

## Как устроен скролл

- **Плавность** — [Lenis](https://github.com/darkroomengineering/lenis) (лежит локально в `assets/js/vendor`), инерционная прокрутка колесом; на телефонах используется родной скролл.
- **«Залипающие» сцены** — секция высотой в несколько экранов с `position: sticky` внутри: слайд стоит на месте, а при прокрутке меняется картинка.
  1. **Hero** — 4 ракурса статуи сменяют друг друга, выноски с линиями дорисовываются под каждый ракурс.
  2. **Description** — «камера» плавно наезжает на крылья → хитон → драпировки, текст меняется синхронно.
  3. **Chronologie** — вертикальный скролл двигает ленту дат по горизонтали.
  4. **Louvre** — камера отъезжает от ночной пирамиды Лувра.
- **Удержание и мягкий доводчик** — каждый слайд какое-то время держится неподвижно; если остановиться посередине перехода, страница мягко доезжает до ближайшего слайда, поэтому полупрозрачная смесь двух картинок никогда не остаётся на экране.
- **Производительность** — один цикл `requestAnimationFrame`, размеры кэшируются только при resize, анимируются только `transform`/`opacity`; все изображения декодируются заранее (прелоадер), поэтому при первом показе нет подвисаний. На всём протяжении страницы держится стабильные 60 fps.
- Учитывается `prefers-reduced-motion`.
