# Global Group Development — сайт

Сайт строительной компании: строительство домов и производство блоков из полистиролбетона.

- **Стек:** Vite, ванильный JS, Three.js (3D), Lenis (плавный скролл), шрифты Prata (заголовки и цифры) и Manrope (текст и интерфейс), подключены локально, с кириллицей.
- **Фото и 3D:** фотографии домов (главный экран, проекты, журнал) лежат в `assets/photos/`. Студийные кадры блоков, интерьер и стройплощадка отрендерены в Blender (Cycles) из сцен в папке `3d/`. На сайте две WebGL-сцены: блок на каменном постаменте в разделе «Технология» (стоит неподвижно; при выборе свойства показываются размеры, лупа со срезом или капли воды) и дом, который строится при прокрутке, в разделе «Как мы строим».
- **Адаптивность:** вёрстка рассчитана на телефоны от 360 px и широкие экраны до 2560 px.
- **Доступность:** уважается `prefers-reduced-motion`, у всех 3D-сцен есть статичная замена, если WebGL недоступен.

## Запуск

```bash
npm install
npm run dev       # локальный сервер разработки
npm run build     # production-сборка в dist/
npm run preview   # просмотр сборки
```

Папку `dist/` можно разместить на любом статическом хостинге (Nginx, Netlify, Vercel, GitHub Pages, Яндекс Object Storage).

## Посмотреть без установки

В папке `dist/` лежит готовая сборка сайта. Чтобы открыть её без Node.js и npm:

1. Установите в VS Code расширение **Live Server** (автор Ritwick Dey).
2. Откройте файл `dist/index.html`, кликните по нему правой кнопкой и выберите **Open with Live Server**.

Открыть `index.html` двойным кликом не получится: браузер не запускает скрипты сайта с локального диска, нужен любой локальный сервер.

## Структура

```
index.html              страница; разделы подключаются из partials/
partials/               разметка разделов (шапка, главный экран, проекты, блоки…)
src/styles/             дизайн-система и стили разделов
src/js/                 поведение: скролл, шапка, карусель, калькулятор, форма…
src/webgl/              3D-сцены на Three.js / WebGL
src/data/               проекты домов (с планировками), статьи журнала, манифест изображений
assets/photos/          исходные фотографии домов
public/img/             оптимизированные изображения (AVIF / WebP / JPEG)
scripts/                обработка фото и рендеров в изображения для сайта
3d/                     исходники 3D-сцен для Blender
```

В `index.html` используются два небольших расширения (плагин в `vite.config.js`):

- `<include src="partials/…"></include>` — вставляет файл раздела;
- `<x-img name="hero" alt="…" sizes="…">` — превращается в `<picture>` с AVIF/WebP/JPEG нужных размеров.

## Что заменить перед запуском

Все цифры, цены и контакты на сайте — **заглушки**, их нужно заменить на реальные данные компании:

| Что | Где |
| --- | --- |
| Часы работы (телефоны, почта и адрес взяты с сайта Global Group Holding) | `partials/header.html`, `partials/contact.html` |
| Ссылки на Telegram и WhatsApp — блок закомментирован, раскомментируйте и вставьте ссылки | `partials/contact.html` |
| Статистика компании: 12 лет, 340+ домов, 60 000 м³ в год, гарантия 10 лет | `partials/about.html`, `partials/process.html` |
| Цены на блоки, размеры поддонов, условия доставки | `partials/blocks.html` и `src/js/calc.js` (константы `BLOCKS`, `GLUE_BAG`) |
| Проекты домов: площади, цены комплектаций, сроки, описания, планировки | `src/data/projects.js` и карточки в `partials/projects.html` |
| Технические характеристики блоков (теплопроводность, прочность, морозостойкость) | `partials/technology.html` — сверить с паспортом качества вашего производства |
| Текст политики конфиденциальности и реквизиты | `partials/dialogs.html` |

### Форма заявки

Сейчас форма проверяет поля и показывает подтверждение, но никуда не отправляет данные. Чтобы заявки приходили, укажите адрес обработчика (CRM, вебхук Telegram-бота, почтовый сервис):

```html
<form class="form" data-form data-endpoint="https://example.com/lead" …>
```

Форма отправит `POST` с JSON: `interest`, `name`, `phone`, `message`, `consent`, `page`.

## Изображения и 3D-рендеры

Готовые изображения уже лежат в `public/img/`.

**Фотографии домов.** Чтобы заменить фото, положите новый файл в `assets/photos/` под тем же именем (`hero.webp` — главный экран, `sosny.webp`, `yasen.webp`, `linia.webp`, `sever.webp` — карточки проектов) и выполните `npm run images`. Новый проект добавляется строкой в `JOBS` в `scripts/process-images.mjs`.

**3D-рендеры** пересобирать нужно, только если меняются сцены:

1. Установите [Blender 4.5 LTS](https://www.blender.org/download/lts/).
2. Скачайте бесплатные ассеты Poly Haven (лицензия CC0 — HDRI-небо, текстуры, деревья):
   ```bash
   python3 3d/fetch_assets.py          # по умолчанию в /opt/assets, путь меняется через GGD_ASSETS
   ```
3. Отрендерите сцены (Cycles на процессоре, несколько часов на все кадры):
   ```bash
   BLENDER=/path/to/blender 3d/render_all.sh          # все кадры
   BLENDER=/path/to/blender 3d/render_all.sh interior # только один
   ```
4. Сконвертируйте рендеры в изображения для сайта:
   ```bash
   npm run images
   ```

Сцены описаны кодом (`3d/scenes/*.py`) на общей библиотеке `3d/lib.py` и палитре материалов `3d/kit.py`: интерьер, студийные кадры блоков, макро-съёмка среза блока и стройплощадка.
