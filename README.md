# nightly

Тёмный одностраничный сайт креативной студии **nightly** (identity, motion, 3D), **только для ПК**.
Статический HTML/CSS/JS без сборки: его можно положить на любой хостинг, включая GitHub Pages.

Страница свёрстана под ширину 1440 px и масштабируется пропорционально ширине окна,
поэтому на ноутбуке 1280 px и на мониторе 2560 px композиция выглядит одинаково.
Отдельной мобильной вёрстки нет: телефоны и планшеты показывают ту же ПК-версию, уменьшенную.

## Структура страницы

| Экран | Видео | Раскладка |
|---|---|---|
| 1. Hero | `sphere`: чёрная сфера (исходник №4) | текст слева, видео справа |
| 2. Identity | `radiance`: лицо из лучей (исходник №3) | видео слева, текст справа |
| 3. Motion | `rain`: фигура под дождём (исходник №2) | текст слева, видео справа |
| 4. 3D & CGI | `offering`: женщина из частиц (исходник №1) | видео слева, текст справа |
| 5. Studio | без видео | манифест и три принципа |
| Футер | без видео | крупный логотип, год, местное время посетителя |

Текст всегда стоит в своей колонке на чёрном фоне и никогда не перекрывает видео.

## Как сделаны плавные бесшовные циклы (60 к/с)

- `assets/film/<name>.mp4`: один цикл в 60 кадров в секунду (H.264). Исходники были 25 к/с;
  промежуточные кадры дорисованы интерполяцией движения, в том числе на стыке цикла.
  Чтобы цикл состоял из целого числа кадров, ролики на 0,96 и 0,48 с замедлены на 0,7 %, а сфера длится ровно 6 с.
- Скрипт `assets/js/main.js` декодирует ролик аппаратным видеодекодером браузера (WebCodecs)
  и рисует кадры на canvas точно по времени. Затем снова подаёт тот же цикл.
  Видео никогда не перематывается и не зависит от правил автозапуска, поэтому стыка не видно.
- Пока ролик за пределами экрана, его часы стоят, а при возвращении он продолжает с того же кадра.
- `assets/anim/<name>.avif` и `.webp`: анимированные картинки 25 к/с, запасной вариант
  для браузеров без WebCodecs.
- Чёрный фон «прижат» к чистому `#000` и совпадает с фоном страницы, поэтому краёв кадра не видно.

Исходные видео лежат в `media-src/`. Чтобы пересобрать всё после замены, нужен `ffmpeg`:

```sh
tools/encode-animations.sh        # всё
tools/encode-animations.sh film   # только ролики 60 к/с
```

## Локальный запуск

Ролики загружаются через `fetch`, поэтому откройте сайт через локальный сервер (двойной клик по `index.html` покажет только запасные картинки):

```sh
python3 -m http.server 8000
# затем http://localhost:8000
```

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → выберите ветку и папку `/ (root)`.

## Что внутри

- `index.html`: разметка и тексты (на английском).
- `assets/css/style.css`: стиль, цвета и шрифты задаются переменными в `:root`.
  Шрифты: Cormorant Garamond и Hanken Grotesk (Google Fonts).
- `assets/js/main.js`: проигрыватель роликов 60 к/с, плавный скролл, мягкое появление блоков, лёгкий параллакс, часы.
- `assets/vendor/lenis.min.js`: Lenis 1.3.26 (MIT), плавный скролл.

Если в системе включено «уменьшение движения», плавный скролл, параллакс и анимации появления
отключаются, а сами анимации продолжают крутиться.
