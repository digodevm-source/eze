# eze — California Modulars

Полноэкранный сайт-презентация ADU (модульных домов), сделанный по видео-референсу.

## Запуск

Сборка не нужна — это статический сайт.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Шрифты подгружаются с Google Fonts, поэтому нужен интернет.

## Управление

- Колесо мыши, тачпад, свайп, стрелки, PageUp/PageDown, пробел, Home/End.
- Меню в шапке; на телефоне — кнопка-бургер со списком всех разделов.
- Поиск (лупа): ищет по разделам и их текстам, Enter открывает первый результат.
- Телефон в шапке, «CONTACT US» и карточка консультации открывают форму заявки с контактами.
- На последнем экране индикатор справа внизу превращается в «Back to top».
- Ссылки вида `index.html#why` открывают нужный экран, `#contact` — форму.
- Esc закрывает поиск, меню, форму и просмотр фото.

## Что заменить перед запуском

- **Контакты** в форме (`index.html`, блок `#contact`): телефон `+1 (800) 555-0199` (номер из вымышленного диапазона) и почта `hello@californiamodulars.com` — замените на настоящие.
- **Отправка заявок:** форма проверяет поля и показывает подтверждение, но заявки пока никуда не уходят. Укажите адрес приёмника (например, Formspree) в `FORM_ENDPOINT` в `assets/js/main.js` — заявки будут отправляться туда в JSON.
- **Подписи проектов** (названия, площадь, город) — примеры, поправьте под реальные объекты.

## Структура

```
index.html
assets/css/style.css   — вёрстка (единицы привязаны к кадру 673×379 → масштаб 1:1 на любом 16:9)
assets/js/main.js      — движок слайдов, анимации, карусель, слайдер, калькулятор, поиск, меню, форма
assets/js/logo3d.js    — 3D-логотип на three.js (подгружается после первого экрана)
assets/vendor/three.min.js
assets/img/            — изображения
```

Изображения взяты из кадров видео-референса. Наложенный текст с них стёрт, затем они увеличены нейросетью Real-ESRGAN x4.
