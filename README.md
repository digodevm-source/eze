# eze — California Modulars

Полноэкранный сайт-презентация ADU (модульных домов). Сделан по видео-референсу 1:1:
те же экраны, тексты, позиции, шрифты и анимации.

## Запуск

Сборка не нужна — это статический сайт.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно открыть и просто `index.html` двойным кликом. Шрифты подгружаются с Google Fonts, поэтому нужен интернет.

## Управление

- Колесо мыши, тачпад, свайп, стрелки, PageUp/PageDown, пробел, Home/End.
- Пункты меню переключают экраны.
- Внутри `maximize` и `projects` колесо сначала листает карусель или слайдер, потом переходит на следующий экран.
- Ссылки вида `index.html#why` открывают нужный экран сразу.

## Анимации

- Буквы заголовков проявляются по одной: сдвиг, размытие, «разрежённый» вход. Уходят они с конца, как при стирании.
- Цифры в Maximize «вырастают» по одной.
- Карточка фото вырастает из линии и схлопывается в линию.
- Фото-экраны наезжают снизу с параллаксом, финальный экран «вытирается» снизу вверх.
- Плавающая бежевая CTA-кнопка меняет форму между экранами: карточка → кнопка.
- Кастомный курсор: точка, а над слайдером проектов — большой круг со стрелкой.

## Структура

```
index.html
assets/css/style.css   — вся вёрстка (единицы привязаны к кадру 673×379 → масштаб 1:1 на любом 16:9)
assets/js/main.js      — движок слайдов, анимации, карусель, слайдер, калькулятор
assets/js/logo3d.js    — 3D-логотип на three.js
assets/vendor/three.min.js
assets/img/            — изображения
```

Изображения взяты из кадров видео-референса. Наложенный текст с них стёрт (inpainting), затем они увеличены нейросетью Real-ESRGAN x4.
