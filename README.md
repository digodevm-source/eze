# Solis Art — Winged Victory of Samothrace

Одностраничный англоязычный сайт по референсу «Solis Art»: тёмная эстетика, статуя на чёрном, плавный «видео»-скролл.

## Как открыть

Статический сайт, сборка не нужна:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

(Можно открыть и `index.html` напрямую, но через локальный сервер шрифт и всё остальное грузятся надёжнее. Подходит любой статический хостинг, например GitHub Pages.)

## Как устроен скролл

- **Плавность** — [Lenis](https://github.com/darkroomengineering/lenis) (лежит локально в `assets/js/vendor`) смягчает прокрутку мышью и тачпадом. Поверх этого каждая сцена плавно «догоняет» позицию скролла, поэтому и на телефоне/планшете пальцем всё идёт мягко.
- **«Залипающие» сцены** — секция высотой в несколько экранов с `position: sticky` внутри: слайд стоит на месте, а при прокрутке меняется картинка.
  1. **Hero** — 4 ракурса статуи. Смена идёт через затемнение: текущий ракурс чуть приближается и уходит в темноту, следующий проявляется из темноты, поэтому две фотографии никогда не накладываются друг на друга. Выноски с линиями дорисовываются под каждый ракурс.
  2. **Description** — «камера» плавно наезжает на крылья → хитон → драпировки, текст меняется синхронно.
  3. **Timeline** — вертикальный скролл плавно двигает ленту дат по горизонтали.
  4. **Louvre** — камера отъезжает от ночной пирамиды Лувра.
- **Удержание и мягкий доводчик** — в первых двух сценах каждый слайд какое-то время держится неподвижно; если остановиться посередине перехода, страница мягко доезжает до ближайшего слайда.
- **Производительность** — один цикл `requestAnimationFrame`, размеры кэшируются только при resize, анимируются только `transform`/`opacity`; все изображения декодируются заранее (прелоадер). Стабильные 60 fps по всей странице.
- Учитывается `prefers-reduced-motion`.
- Все фотографии — public domain или CC0, указывать авторов на сайте не нужно (источники — в `CREDITS.md`).
