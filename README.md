# LIPA — сайт цветочной лавки

Одностраничный сайт для цветочной лавки **LIPA flowers shop**: Москва, ул. Нижние Мнёвники, 9, подъезд 10.
Сделан в духе прошлых проектов dgd studio: прелоадер, плавный скролл, сцены, которые раскрываются при прокрутке, подпись внизу.

## Запуск

Сборка не нужна, это чистые HTML, CSS и JS. Откройте `index.html` или поднимите любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Публикация: GitHub Pages, Netlify, Vercel или любой хостинг статики. Достаточно загрузить папку как есть.

## Что нужно уточнить у лавки

Всё это меняется в одном месте, в объекте `CONFIG` в начале `assets/js/main.js`:

| Что | Где | Сейчас |
|---|---|---|
| Ссылка на Telegram | `CONFIG.telegram` | пусто, поэтому все кнопки Telegram скрыты |
| Полный режим работы | `CONFIG.hours` | «Открываемся в 10:00» |
| Ссылка на карточку в Яндекс Картах | `CONFIG.yandexMaps` | поиск по названию и адресу |
| Куда приходят заявки | `CONFIG.formEndpoint` | пусто: форма работает как демо и никуда не отправляет |
| Подпись «Демо-версия сайта» в подвале | `CONFIG.demo` или ссылка с `?demo=0` | включена |

Ещё нужно:

- **Фото в хорошем качестве.** Сейчас фото вырезаны из скриншотов Telegram-канала (около 450 px) и увеличены нейросетью Real-ESRGAN x4, поэтому на большом экране они мягкие. Оригиналы из канала заменят их один к одному: файлы в `assets/img/` с теми же именами.
- **Цены остальных букетов.** Сейчас у них «Цена по запросу». Цены в `index.html`, в карточках `.card`.
- **Доставка.** Про доставку на сайте ничего не сказано, пока это неизвестно.
- Составы букетов подписаны по фото. Флорист может поправить названия.

## Скорость

Сайт рассчитан на плавные 60 кадров в секунду, в том числе на iPad:

- Арка на главном экране растёт только через `transform: scale`, фото внутри получает обратный масштаб. Форма арки и фото не перерисовываются во время прокрутки, всю работу делает видеокарта.
- В шапке, нижней панели и окне заявки нет `backdrop-filter`: размытие фона под шапкой пересчитывается каждый кадр прокрутки и сильно тормозит на iPad.
- JS не записывает стили, если значение не изменилось, и не трогает сцены, которые сейчас не на экране.
- Прелоадер уезжает вверх через `transform`, а не `clip-path`.

## Карта

[MapLibre](https://maplibre.org) с бесплатными тайлами [OpenFreeMap](https://openfreemap.org): без рекламы, без ключа, разрешено коммерческое использование. Стиль перекрашен в цвета сайта (`tintMapStyle` в `assets/js/main.js`), подписи на русском.

- Библиотека и тайлы грузятся, только когда до контактов доходит прокрутка.
- Колесо мыши и один палец листают страницу. Карту двигают Ctrl/⌘ + колесо или два пальца, поэтому карта не перехватывает прокрутку.
- Метка стоит на координатах дома из `CONFIG.coords`. Если карта не загрузилась, на её месте ссылка на Яндекс Карты.
- Подпись источников (OpenFreeMap, OpenMapTiles, OpenStreetMap) обязательна по лицензии, её нельзя убирать.

## Заявки

Форма проверяет имя и телефон. Если в `CONFIG.formEndpoint` указан адрес, заявка уходит туда POST-запросом в JSON:
`name`, `phone`, `bouquet`, `comment`, `page`. Подойдёт Formspree или Telegram-бот, который пересылает заявки флористу.

## Структура

```
index.html
assets/
  css/style.css      — стили (цвета и шрифты в переменных в начале файла)
  js/main.js         — CONFIG с данными лавки, анимации и интерактив
  vendor/lenis.min.js — Lenis 1.1.20, плавный скролл (MIT)
  vendor/maplibre-gl.* — MapLibre GL JS 5.6.0, карта (BSD-3-Clause)
  fonts/             — Unbounded (заголовки и цифры) и Manrope (текст), variable, кириллица и латиница, SIL OFL
  img/               — фото в WebP, favicon
```
