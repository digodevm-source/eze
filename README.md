# Altai Ridge — сайт коттеджного посёлка

Одностраничный сайт-презентация в формате «слайдов»: 10 полноэкранных карточек, которые плавно сменяют друг друга. Текущая уходит вглубь и затемняется, следующая наезжает поверх.

## Запуск

Сборка не нужна, это чистые HTML, CSS и JS. Достаточно открыть `index.html` или поднять любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Публикация: GitHub Pages (Settings → Pages → Deploy from branch → корень), Netlify, Vercel или любой хостинг статики.

### Переходы между слайдами

На компьютере сайт работает как презентация: одно движение колесом, свайп или стрелка переключают ровно один слайд. У каждого перехода своя анимация:

| Переход | Как появляется следующий слайд |
|---|---|
| 01 → 02 | Въезжает слева, контент догоняет с небольшой задержкой |
| 02 → 03 | Камера «пролетает» сквозь экран, следующий слайд приближается из глубины |
| 03 → 04 | Раскрывается кругом из центра |
| 04 → 05 | Открывается «окно» в долину, камера отъезжает назад |
| 05 → 06 | Поднимается снизу с 3D-поворотом, текущий наклоняется назад |
| 06 → 07 | Закрываются и открываются вертикальные шторки |
| 07 → 08 | Наискосок проходит диагональная шторка |
| 08 → 09 | Слайд «сдаётся» из угла, как карта |
| 09 → 10 | Расходятся «двери», камера влетает в дом |

Назад проигрывается та же анимация в обратную сторону. Прыжки через меню и точки справа идут через вертикальную шторку. Код переходов собран в массиве `FX` в `assets/js/main.js`.

- **Клавиатура**: `↓` / `↑`, `←` / `→`, `PageDown` / `PageUp`, `Space`, `Home`, `End`.
- **Производительность**: анимируются только `transform`, `opacity` и `clip-path`. Одновременно отрисовываются только два слайда. Фото заранее декодируются в фоне, поэтому переход не ждёт картинку.
- **Телефоны и низкие экраны** (уже 1024 px или ниже 620 px): обычная прокрутка, карточки въезжают каждая по-своему (масштаб, 3D-наклон, скос).
- При системной настройке «Уменьшить движение» анимации отключаются.

## Как редактировать

- **Тексты, цены, характеристики** находятся в `index.html`. Характеристики проектов лежат в атрибутах кнопок `.plist__item` (`data-price`, `data-area` и т. д.).
- **Фото** лежат в `assets/img/`, у каждого два размера: `name.webp` (большой) и `name-sm.webp` (до 960 px). Чтобы поставить свои рендеры, замените файлы с теми же именами.
- **Цвета и шрифты** задаются переменными в начале `assets/css/style.css` (`--accent`, `--bg` …).
- **Отправка заявок.** Сейчас форма проверяет поля и показывает «Спасибо», но никуда не отправляет. Чтобы подключить CRM, почту или Telegram-бота, задайте адрес обработчика перед подключением `main.js`:

  ```html
  <script>window.ALTAI_FORM_ENDPOINT = 'https://your-backend.example/lead';</script>
  ```

  Данные уходят POST-запросом в JSON: `name`, `phone`, `format`, `comment`, `subject`.

> Цифры, цены, телефон, e-mail и домен взяты из макета или придуманы как заглушки. Перед публикацией замените их на реальные.

## Структура

```
index.html
assets/
  css/style.css      — стили
  js/main.js         — анимации и интерактив
  vendor/            — gsap 3.12.5, ScrollTrigger, lenis 1.1.20
  fonts/             — Jost и Manrope (variable), Unbounded 600 для крупных надписей; кириллица и латиница
  img/               — фото в WebP
```
